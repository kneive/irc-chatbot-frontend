# IRC Chatbot Frontend

Frontend for an IRC chatbot.

## Info

I started this project as a personal research project to gain practical knowledge in using React and responsive web design.

## Overview

This project provides a web-based dashboard for monitoring and managing an IRC chatbot. It features a terminal-style interface component for accessing data gathered from the chatbot through a RESTful API.

## Tech stack

- **Frontend:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Data Fetching:** TanStack React Query
- **HTTP Client:** Axios
- **Routing:** React Router

## Prerequisites

- Node.js
- npm

## Installation

```Shell
# Install dependencies
npm install
```

## Usage

```Shell
# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
